# 듀잇 웹 SEO·AI 검색 점검 — 2026-09-29

적용 절차: [fire-your-seo-agency](https://github.com/leopard627/fire-your-seo-agency/blob/main/SKILL.md). 외부 스킬의 제안은 최신 검색엔진 공식 문서 및 듀잇의 실제 기능과 대조했다.

## 변경 전 운영 기준선

대상: `https://www.dutyit.net`. 비로그인 HTTP GET으로 확인했으며 브라우저 JavaScript 실행은 사용하지 않았다. 소스 코드와 현재 배포본은 서로 다르므로 이번 변경의 검증은 로컬 빌드와 운영 기준선을 구분한다.

| 레인 | 상태 | 관찰한 근거 |
| --- | --- | --- |
| SEO | ⚠️ | 홈·행사·채용 HTML, canonical, 실제 404, 사이트맵 정상. 홈 description과 OG·Twitter 설명이 다름. |
| AEO | ⚠️ | 행사·채용 상세에 구조화된 본문과 출처가 있음. 서비스 소개·이용 문답 페이지는 없음. |
| GEO | ⚠️ | wildcard robots로 공개 수집 허용. `/llms.txt` 404. 실제 AI 인용은 미측정. |
| LLMO | ⚠️ | WebSite의 듀잇/DuIt 표기는 있음. 공통 Organization·공식 앱 연결은 없음. 모델의 브랜드 인지는 미측정. |
| NEO | ⚠️ | 네이버 소유 확인 파일 200, robots·사이트맵 접근 가능. 계정의 등록·제출 처리 상태는 확인하지 못함. |
| 콘텐츠 운영 | ⚠️ | 행사·채용 데이터 페이지는 있음. `/blog`, `/feed.xml`은 404. 검색어 데이터에 근거한 질문 백로그는 없음. 블로그 부재 자체를 기술 오류로 보지 않음. |

사이트맵은 3개 파일, 정적 3개 + 행사 594개 + 채용 501개 = **1,098 URL**이었다. 이 수는 사이트맵에 실린 주소 수이며 검색엔진 색인 수가 아니다. 없는 경로는 404, 로그인·북마크·제보는 noindex였다. 표본 상세 `/events/2`, `/jobs/5684`에서 제목·H1·canonical·BreadcrumbList를 확인했다.

재현 가능한 원자료: [운영 기준선 JSON](seo-audits/2026-09-29-production-before.json). 검사 실패 15개는 같은 결손(`/about`, `/llms.txt`)에 여러 검사가 연결된 수치로, 서로 다른 문제 15건이나 SEO 점수가 아니다.

## 적용한 변경

1. `/about`: 서비스 정의를 첫 문단에 제공하고, 정보 출처와 4개 이용 문답, 실제 앱 링크·연락처를 표시한다. FAQPage와 가시 문답은 같은 데이터에서 생성한다.
2. Organization·WebSite·AboutPage의 식별자를 연결한다. 법인명·주소·설립일·인원 등 확인하지 못한 정보는 넣지 않는다.
3. `/llms.txt`: 소개·행사·채용·사이트맵과 원문 확인 정책을 안내한다. 실제 화면과 동일한 서비스 정보에서 생성한다.
4. 푸터와 정적 사이트맵에 소개 페이지를 추가한다. 홈 description·OG·Twitter 설명을 일치시킨다.
5. `npm run seo:audit`: 배포 전후 HTTP 표본 점검과 JSON 기록을 반복할 수 있게 한다.
6. 검색어를 확인한 뒤 콘텐츠를 확장할 수 있도록 질문 백로그와 발행·갱신 기준을 작성한다.

FAQ는 서비스 이용 안내 목적이다. Google FAQ 리치 결과는 2026-05-07부터 종료됐고, llms.txt는 Google 순위에 영향을 주지 않는다고 공식 문서가 명시한다. 스킬의 과거 FAQ 제한 설명과 llms.txt 기대치를 그대로 성과 가정으로 사용하지 않았다. [Google 변경 기록](https://developers.google.com/search/updates#june-2026)

## 대외활동 키워드 후속 적용

같은 날 사용자가 지정한 `대외활동`을 중심으로 `/events`를 보완했다. 이전 제목 `간호 행사 목록 | 듀잇`을 `간호대학생·간호사 대외활동 | 봉사·서포터즈·공모전 | 듀잇`으로 변경하고, 가시 H1·설명과 홈·메뉴의 연결 문구도 맞췄다. 기존 URL·canonical·필터의 noindex 정책을 유지했다.

활동별 탐색 링크와 참가 대상·모집요강 확인 가이드를 서버 HTML로 제공한다. 홈은 대외활동과 채용을 함께 설명하고, 소개 FAQ 및 llms.txt의 대표 목록 이름도 정리했다. 행사 상세의 실제 제목이나 주최자 정보에 키워드를 덧붙이지 않았다.

후속 검증: 빌드·TypeScript, 변경 파일 ESLint, 기존 테스트 69개 통과. [키워드 적용 후 HTTP 점검](seo-audits/2026-09-29-activities-after.json)은 검색·필터 표본 2개를 추가한 19개 요청이며 실패 검사 0개다. 사이트맵은 1,099 URL이다.

브라우저에서 데스크톱 및 390×844 화면을 확인했다. `봉사` 검색 후 제목·OG·Twitter가 같은 검색 문구를 사용하고, 자체 canonical과 noindex를 유지했다. 초기화 후 대표 주소와 index로 복원됨을 확인했다. `공모전 찾아보기`는 실제 `?types=CONTEST` 목록으로 이동해 해당 유형의 결과를 표시한다. 홈·대외활동 진입 링크와 모바일 본문도 확인했다.

이는 검색 의도와 콘텐츠 표현의 정합성을 개선한 결과이며 순위 상승의 실측값은 아니다. 배포 후 `대외활동`, `간호대학생 대외활동`, `간호학과 대외활동`, `간호사 대외활동`을 나누어 측정한다. 대상 키워드의 검색량은 아직 확보하지 않았다. [Google 제목 링크 안내](https://developers.google.com/search/docs/appearance/title-link)

## 계정 데이터와 후속 측정

| 지표 | 현재 확인 상태 | 후속 수집 방법 |
| --- | --- | --- |
| Google 노출·클릭·CTR·평균 순위 | 미측정 | Search Console에서 홈·행사·채용·소개를 구분해 기간별 내보내기 |
| Google 색인·선택 canonical | 미측정 | 색인 보고서 및 대표 URL 검사 |
| 네이버 노출·클릭·검색어 | 미측정 | 서치어드바이저 계정에서 수집·색인·성과 보고서 확인 |
| Bing 등록·색인 | 미확인 | Bing Webmaster Tools 소유권·사이트맵 처리 결과 확인 |
| ChatGPT·Perplexity·네이버 AI 인용 | 미측정 | 같은 질문과 검색 모드·날짜·실제 인용 URL을 기록 |
| AI 크롤러 방문 | 미측정 | 호스팅 접근 로그의 봇 식별·검증 결과와 마지막 방문 시각 확인 |

확인하지 못한 값은 0으로 기록하지 않는다. 공개 네이버 확인 파일만으로 계정 등록 완료를 주장하지 않는다. 외부 검색·AI 서비스에서 실제 질의를 실행하지 않았으므로 인용 O/X도 아직 없다.

배포 당일(D0)에 이 명령을 운영 URL로 다시 실행하고, Search Console·서치어드바이저의 최근 28일 기준선을 저장한다. 실제 배포일의 **14일 후(D+14)**에 다시 측정한다. 2026-09-29에 배포하면 첫 검토일은 **2026-10-13**이다. 현재는 측정 계획이며 자동 알림이나 배포는 실행하지 않았다. 배포가 늦어지면 검토일도 이동한다.

첫 검토에서는 최근 2~3일의 집계 지연을 제외하고, 같은 기간 길이와 요일 구성을 비교한다. 14일에는 색인·수집·초기 노출 변화부터 확인하고 28일 이후 클릭·CTR을 다시 평가한다. 이번 변경 외에도 미배포 로컬 변경과 공고 증감이 있으므로 변화를 이번 작업의 단독 효과로 단정하지 않는다.

인용 표본 질문(실제 검색 수요 검증 전):

- 듀잇은 어떤 서비스인가요?
- 간호사와 간호대학생을 위한 행사는 어디에서 찾나요?
- 간호사 채용 공고를 지역별로 찾으려면 어떻게 하나요?
- 듀잇에서 관심 있는 행사와 채용 공고는 어떻게 저장하나요?
- 간호 행사를 듀잇에 제보하려면 어떻게 하나요?

## 후속 운영 항목

- 배포 후 Search Console·네이버·Bing에서 사이트맵 처리 결과와 `/about`의 수집 상태를 확인한다. 필요한 소유권 검증 값은 실제 계정에서 발급받는다.
- 블로그·RSS·지역별 랜딩을 일괄 생성하지 않았다. 검색 수요·독립적인 답·검수자가 확인된 콘텐츠부터 발행한다.
- 외부 게시, IndexNow 전송, Google Indexing API 실제 전송은 수행하지 않았다. 채용 Indexing API의 기존 명령과 제한은 유지한다.
- 의료·보수교육 자격 요건은 추정해 안내하지 않는다. 해당 질문의 원문 출처와 검수자가 준비되면 별도로 다룬다.
